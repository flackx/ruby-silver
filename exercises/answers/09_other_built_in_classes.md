# Answers 9: Other built-in classes

1. `ArgumentError`. `Integer()` requires the complete text to be a valid integer representation.
2. `["a", "b", "c"]`. The three-dot Range excludes `"d"`.
3. `[true, false]`. String inherits from Object but is not exactly an Object instance.
4. `w` and `w+`.
5. `NoMethodError`. `basename` is a `File` class method, not a `Dir` class method.
