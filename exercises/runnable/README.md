# Runnable exercise companions

Each Ruby file corresponds to the same-numbered Markdown exercise in the parent directory.

1. Read the Markdown prompt and write your prediction first.
2. Open the matching `.rb` file in RubyMine.
3. Fill in `TODO` values or uncomment an intentionally failing line only after predicting it.
4. Run the file with Ruby 3.1.7.
5. Compare with the separate script under `answers/` and the fuller Markdown explanation under `../answers/`.

Intentional syntax and runtime failures are commented out by default so every unfinished companion remains runnable. Uncomment only the task you are testing; comment it again before moving on.
