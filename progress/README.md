# Progress system

Use [topics.md](topics.md) for section status and [mistake_log.md](mistake_log.md) for individual rules.

Statuses:

- **Not started** — note not yet read.
- **Learning** — note read or exercises attempted, but recall is unreliable.
- **Review** — a misconception or repeated mistake remains.
- **Secure** — at least 80% on two attempts separated by 24–48 hours.

Confidence is not evidence. Record scores and the rule that produced each mistake.
