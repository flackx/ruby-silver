# Quiz 1: Language basics

1. Which values are falsey? **Choose two.**
   - A. `0`
   - B. `nil`
   - C. `false`
   - D. `[]`

2. Which are valid local variable names? **Choose two.**
   - A. `2banana`
   - B. `_banana`
   - C. `potato2`
   - D. `class`

3. What does `p((1...4).to_a)` print? **Choose one.**
   - A. `[1, 2, 3, 4]`
   - B. `[1, 2, 3]`
   - C. `1...4`
   - D. A runtime exception

4. What is printed? **Choose one.**
   ```ruby
   x = 2
   case x
   when 1..3 then puts 'banana'
   when 2..4 then puts 'potato'
   end
   ```
   - A. `banana`
   - B. `potato`
   - C. Both lines
   - D. Nothing

5. What does `p(puts('x'))` print? **Choose one.**
   - A. `x` only
   - B. `nil` only
   - C. `x`, then `nil` on the next line
   - D. `"x"`, then `nil`
