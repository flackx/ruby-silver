# Quiz 3: Operators

1. What is printed? **Choose one.**
   ```ruby
   x = true and false
   p x
   ```
   - A. `true`
   - B. `false`
   - C. `nil`
   - D. Syntax error

2. Which operators short-circuit? **Choose two.**
   - A. `&&`
   - B. `||`
   - C. `&`
   - D. `|`

3. What does `p(8 % 3)` print? **Choose one.**
   - A. `1`
   - B. `2`
   - C. `2.0`
   - D. `3`

4. What does `p([1, 2, 3] & [2, 3, 4])` print? **Choose one.**
   - A. `[1, 4]`
   - B. `[2, 3]`
   - C. `[1, 2, 3, 4]`
   - D. `true`

5. Which expressions evaluate to `true`? **Choose two.**
   - A. `1 == 1.0`
   - B. `nil || false`
   - C. `!nil`
   - D. `false && true`
