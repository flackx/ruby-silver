# Quiz 9: Other built-in classes

1. What does `p(9.divmod(4))` print? **Choose one.**
   - A. `[2, 1]`
   - B. `[2.25, 0]`
   - C. `[1, 2]`
   - D. `2`

2. Which conversions raise for the text `"8x"`? **Choose one.**
   - A. `"8x".to_i`
   - B. `Integer("8x")`
   - C. Both
   - D. Neither

3. Which statements are true? **Choose two.**
   - A. A String is normally `is_a?(Object)`.
   - B. A String is `instance_of?(Object)`.
   - C. `Kernel` supplies broadly available methods such as `puts`.
   - D. Ordinary classes default to a superclass of `Module`.

4. Which modes append writes rather than truncate first? **Choose two.**
   - A. `a`
   - B. `a+`
   - C. `w`
   - D. `r+`

5. Which are valid class-method calls? **Choose two.**
   - A. `Dir.pwd`
   - B. `Dir.basename('a/b')`
   - C. `File.basename('a/b')`
   - D. `File.chdir('a')`
