# Quiz 8: Strings, symbols, and regular expressions

1. What does `p('banana'.sub('a', 'o'))` print? **Choose one.**
   - A. `"bonana"`
   - B. `"bonono"`
   - C. `"banana"`
   - D. `nil`

2. Which create Arrays of Symbols? **Choose two.**
   - A. `%i[banana potato]`
   - B. `[:banana, :potato]`
   - C. `%w[banana potato]`
   - D. `["banana", "potato"]`

3. What does `p('abc'[1])` print in Ruby 3.1? **Choose one.**
   - A. `98`
   - B. `"b"`
   - C. `:b`
   - D. `["b"]`

4. Which regexes match only the complete String `ruby`, ignoring case? **Choose two.**
   - A. `/\Aruby\z/i`
   - B. `/^ruby$/i`
   - C. `/ruby/i`
   - D. `/\A(?:ruby)\z/i`

5. What does `p('x12'.to_i)` print? **Choose one.**
   - A. `12`
   - B. `0`
   - C. `nil`
   - D. `ArgumentError`
