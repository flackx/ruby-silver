# Quiz 6: Arrays and hashes

1. What does `p([8, 6, 4, 2][1, 2])` print? **Choose one.**
   - A. `[6, 4]`
   - B. `[6]`
   - C. `[6, 4, 2]`
   - D. `6`

2. Which methods mutate an Array? **Choose two.**
   - A. `push`
   - B. `+`
   - C. `concat`
   - D. `select`

3. Which Hash methods are aliases for checking a key? **Choose two.**
   - A. `key?`
   - B. `value?`
   - C. `member?`
   - D. `contain?`

4. What does `p({}.fetch(:x, 4))` print? **Choose one.**
   - A. `nil`
   - B. `4`
   - C. `:x`
   - D. `KeyError`

5. Which creates two independent empty Arrays? **Choose one.**
   - A. `Array.new(2, [])`
   - B. `[[]] * 2`
   - C. `Array.new(2) { [] }`
   - D. `Array.new([], 2)`
